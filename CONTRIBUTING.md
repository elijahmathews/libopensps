All commits messages should follow the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/)
format. If possible, commits should be signed with an OpenPGP key to verify the
author, but this is not a strict requirement.

Please use the issue templates — they help make sure a report has what's needed to

of opening a public issue.
