# libopensps data release data-v2

Libraries for libopensps (https://github.com/elijahmathews/libopensps), a modernized FSPS, in its standard data format (doc/DATA_FORMAT.md of libopensps). Unpack the archives into one directory (`tools/fetch_data.py ~/opensps-data --release data-v2` does this and verifies every checksum) and point `OPENSPS_DATA_HOME` at it.

## What to cite

Any use: the FSPS papers, Conroy et al. 2009, ApJ, 699, 486 (2009ApJ...699..486C); Conroy & Gunn 2010, ApJ, 712, 833 (2010ApJ...712..833C). In addition, cite the sources of the libraries you use (below). Bibcodes refer to `data_release.bib` (an export from NASA ADS, shipped in this release); every library's `manifest.json` lists the same references under `provenance`.

Redistribution: these files have been distributed publicly with FSPS (https://github.com/cconroy20/fsps). No separate license is stated there; the terms of the original data apply.

## Layout

Each library is one archive, `<kind>-<name>-v<N>.tar.zst` (or `.tar.gz`), holding `libraries/<kind>/<name>/` (a `manifest.json` and raw little-endian arrays); the base archive holds `opensps-data.json`, the small text tables in `data/`, this file and `data_release.bib`. Archives are immutable: a changed library gets a new version and a new archive, and the release manifest `<release>.json` lists, for every library, its version, SHA-256, size and download URLs (mirrors), possibly pointing at archives of an earlier release.
