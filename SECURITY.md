# Security Policy

## Supported Versions

libopensps is pre-1.0 research software under active development. Security fixes are
made against the latest release on `main`; there is no long-term support for older
versions at this stage.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather than
opening a public issue — email **pgp@elijahmathews.com** with details. We'll aim to
acknowledge the report within a few business days and follow up with next steps once
the issue has been assessed.

Please do not disclose the issue publicly until it has been addressed.
